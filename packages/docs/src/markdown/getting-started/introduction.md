## What is QMediaPlayer

QMediaPlayer is a Quasar component package for building HTML5 audio and video players with a refined Quasar-friendly UI. It wraps native media playback in a component that supports source lists, captions, fullscreen controls, dark mode, dense layouts, custom colors, custom icon sets, and language packs.

Use it when you want media playback to feel like part of your Quasar application instead of a browser-default control dropped into the page.

## Features

- HTML5 audio and video playback
- Fullscreen support
- Captions and subtitle tracks
- Native controls when you need them
- Custom colors, backgrounds, and dense layouts
- Language packs for player labels
- Multiple icon-set integrations

## QMediaPlayer Is Not

- An RTSP, RTMP, RTP, or HDS streaming player
- A direct player for YouTube or Vimeo iframe embed URLs
- A DRM/media-streaming platform integration
